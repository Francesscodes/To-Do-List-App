  To-Do List App

A simple and elegant to-do list application built with vanilla JavaScript, HTML, and CSS. Keep track of your tasks with a clean, user-friendly interface and persistent storage.

 Features

- Add Tasks: Quickly add new tasks to your list
- Mark as Complete: Click on any task to toggle its completion status
- Delete Tasks: Remove tasks by clicking the × button
- Persistent Storage: Your tasks are automatically saved to local storage and persist across browser sessions
- Responsive Design: Clean, modern UI with a gradient background

Demo

The app features a purple gradient background with a centered white card interface. Tasks can be marked as complete (with a checkmark and strikethrough) or deleted entirely.

 Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- Local Storage API

 Installation

1. Clone the repository:
```bash
git clone https://github.com/yourusername/todo-list-app.git
```

2. Navigate to the project directory:
```bash
cd todo-list-app
```

3. Open `index.html` in your browser or use a local server.

 Usage

1. Adding a Task: Type your task in the input field and click the "Add" button or press Enter
2. Completing a Task: Click on any task to mark it as complete (adds a checkmark and strikethrough)
3. Deleting a Task: Click the × button on the right side of any task to remove it
4. Automatic Save: All changes are automatically saved to your browser's local storage

 Customization

You can easily customize the app's appearance by modifying the CSS variables in `style.css`:

- Background gradient colors
- Button colors
- Task item styling
- Border radius and spacing
